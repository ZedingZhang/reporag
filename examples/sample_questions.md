# Sample Questions for RepoRAG

## Architecture Questions

- "What is the high-level architecture of this codebase?"
- "How are the main modules organized?"
- "What design patterns are used?"

## Code Location Questions

- "Where is authentication implemented?"
- "Which file contains the main entry point?"
- "Where is the database connection configured?"

## Issue/PR Context Questions

- "Has there been a fix for login timeout?"
- "What are the recent breaking changes?"
- "Is there an open issue about performance?"

## Usage Questions

- "How do I configure the logger?"
- "What are the required dependencies?"
- "How do I run tests?"
